# Giới thiệu

## What?

- Thư mục này dung để lưu các file config cấu hình database, cloud, hạ tầng, scripts của hạ tầng thường devops/cloudops sẽ làm việc với thư mục này

- Nó sẽ gồm 3 loại:
  - Config cấu hình môi trường local dev
  - Config câu hình môi trường dev
  - Config cấu hình môi trường staging (qa)
  - Config cấu hình môi trường production
- Các dạng format file có thể có
  - Tùy vào môi trường chạy/ container /vm /computing cần những file set up nào mà ta có thể chạy

## When?

- File này sẽ được sử dụng, cập nhật xuyên suốt dự án
