# Danh mục nguồn kiến thức

Lưu metadata và nguồn gốc tài liệu bảo dưỡng, bảo hành, bảng giá dùng cho EV Care.
Mỗi nguồn cần có ID, tiêu đề, URL hoặc vị trí gốc, hãng/dòng xe, phiên bản, ngày thu thập và phạm vi áp dụng.

Chỉ ghi nguồn đã kiểm tra. Những nguồn hiển thị trong mock giao diện chưa phải tài liệu đã thu thập hoặc xác minh.

File tải về đặt trong `data/knowledge/`, chỉ mục trong `data/indexes/`; `data/` không được commit.
